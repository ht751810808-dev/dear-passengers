# Cabin Crisis V3 — 画面与动作重做

本轮按官方 Steam 截图和宣传片观察到的造型、材质、光照关系直接制作，不套用用户的个人 Skill。目标是实际缩小视觉差距；不把「已经完全相同」当成未经验证的结论。

参考来源与观察边界沿用 [V2 调研](../v2/research.md)。本次没有获得官方项目文件或可运行原版。官方图片仅用于研究，没有覆盖到游戏画布或假装成实时场景。

## 画面对比

[打开固定机位对比](visual-review.html)。V2 以 `fd7eb75` 的引擎为基准，V3 使用相同拍摄脚本、相机、视线和场景条件。脚本仅在独立本地 QA fixture 中设置镜头，生产页面不暴露测试 API。

## 第一人称与界面

- 蓝色双手改为肩、肘、腕、指节结构。空手、搬运、端餐盘、拿杯子、维修、灭火和驾驶使用不同姿势。
- 操作中的双手朝实际目标方向伸出；远处目标受手臂长度限制，不能宣称所有交互距离都准确接触。
- 实体金属餐盘、纸垫和六份餐食。餐盘随手移动，丢出后继续使用已有的物理与联机同步。
- `V` 键或视图按钮收起 HUD；可按 `V` 或显示界面按钮恢复。暂停与触控操作保留。
- 咖啡、餐食需求图标跟随真实服务状态，供角色吃喝动画使用。

## 人物、机舱和渲染

- 重建长胶囊脸、凸球眼、瞳孔和球壳眼睑；八种服装与发型，花衬衫图案由本地 Canvas 绘制。修复头皮穿发、眼睑相交和大腿陷入座椅的问题。
- 人物带有分层手臂、腿部、头部及注视动作。喝咖啡与吃饭由服务完成状态触发，乘客错峰动作；远端机组有行走、持物和操作姿态。
- 重建宝蓝色软垫、浅色座椅外壳、棕色扶手、大窗框、行李架底板和成组三盏阅读灯。驾驶台增加八个仪表、雷达、开关、顶置显示器与双手握持的操纵杆。
- 火警或低舱压能显示破裂舱壁、碎边和线路，修复后恢复。这是视觉损坏状态，未扩展为任意位置可破坏的物理系统。
- 分层软云、天气变化、透明烟雾与橙色火焰，远景雾化与天空共享天气颜色，去掉原来的青色海天硬边；高画质增加轻量环境反射、接触阴影、HDR 和克制的辉光。低画质绕过后处理。
- 角色静态部件按活动骨骼合批，保留关节动作。渲染器销毁会释放后处理目标、环境贴图和特效纹理。

## 验收方法

- `pnpm test:flight`：25 项飞行模拟、10 项存档与奖励检查。
- `scripts/qa-v3-visuals.mjs`：六个固定镜头、手机比例以及 shader/runtime 错误检查。
- `scripts/qa-v3-rendering.mjs`：实时帧耗、HQ/LQ 切换、横屏 resize、资源销毁与重新创建。
- `scripts/qa-v3-ui.mjs`：通过实际页面启动航班，测试收起/恢复 HUD、暂停及两种手机尺寸。
- 原有引擎交互与双人联机回归继续用于检查美术替换没有破坏任务或同步。

## 本机验收结果

- 模拟与存档测试：35 项通过。
- 引擎实操：9 项通过，覆盖安全带、咖啡、餐食、驾驶、维修、投掷及暂停。
- 双浏览器真实 WebSocket 联机：11 项通过，包括乘客服务、独立背包、共享驾驶、座舱占用互斥、远端暂停及断线清理。
- 实际页面：6 项通过，包括启动航班、隐藏/恢复界面、暂停和 390/844 像素视口布局。
- 六个固定机位及手机比例截图均无 JavaScript/shader 错误。V2 参照和 V3 实拍保存在 `evidence`。
- 当前 Mac 的隔离 Chromium、Metal、DPR 1：四组持续采样的帧间隔中位数为 16.4–16.7 ms，P95 为 18.3–19.2 ms。覆盖高/低画质、横屏调整及销毁重建；不代表实体手机性能。

TypeScript、针对改动的 ESLint、完整发布构建和线上验证结果随发布记录一并保存。

## 仍然存在的差距

人物和机舱均由本项目程序生成；这次没有获得原版美术资产、骨骼动画或渲染参数。形体、光照、云层和动作已有具体改进，但不宣称达到宣传片逐像素一致。当前云层为带明暗的分层透明面片，人物动作是程序动画；没有加入任意破坏、完整布料或软体物理。
